# 项目技术决策记录

本文件集中记录影响项目长期维护的技术选择。普通代码实现和临时调整不记录，后续决策按时间追加，不删除历史。

## 2026-08-10：建立项目基础技术方案

- 状态：已采用
- 使用 Java 25，优先采用适合业务场景的正式语言特性。
- 使用 Spring Boot 4.1.x，不为兼容旧示例降低框架版本。
- 使用 Maven 管理依赖和构建，依赖与插件版本优先交给 Spring Boot Parent 管理。
- Web 层使用 Spring MVC，默认使用嵌入式 Tomcat。
- Lombok 仅用于减少重复代码，不让它进入最终运行时依赖。
- 前端作为独立项目开发，本仓库只维护后端代码。
- 数据库、缓存、认证、消息队列和部署方案在产生实际需求后再选择。
- 不单独维护需求文档；版本变化记录在根目录 `CHANGELOG.md`，长期技术选择记录在本文件。
